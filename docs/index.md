# PyKampala Community Blog

Welcome to the **PyKampala Community Blog** — technical stories, tutorials, and community updates from Python developers in Uganda. Established 2016.

We host **physical and virtual meetups every last Saturday of the month**. This blog extends our [main website](https://pykampala-community.github.io/) with in-depth articles you can read, share, and discuss.
